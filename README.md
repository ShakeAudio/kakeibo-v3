# kakeibo-v3

iPhone のホーム画面に追加して使う家計簿（Webアプリ）。仕様メモ（SPEC.md）は個人的な情報を含むため、手元にだけ置いてリポジトリには入れない。

GAS の URL と合言葉はプログラムに書かず、アプリの設定画面で入力して端末の中だけに保存する。

## いまの状態（2026-10-29）

- 全画面（予算・入力・家計・事業・固定費・負債・分割払い・設定・取引先・案件・カード・銀行）ができている
- `npm run dev` で動かすときだけダミーデータが入る（設定 →「ダミーデータに戻す」で最初の状態に戻せる）
- 公開版はダミーデータなし。GAS の URL と合言葉を入れるまで中身を表示しない
- GAS の URL と合言葉を入れると、スプレッドシートと同期する
  - 開いたとき・電波が戻ったとき・アプリに戻ったとき（1分以上あいたら）に読み込む
  - 画面で変えた内容は送信待ちに積んで送る。送れなければ端末に残し、次につながったときに送る
  - 端末内（localStorage）にも写しを持つので、電波がなくても見られる
  - 接続を消すと、端末の写しも消す（スプレッドシートは消えない）

## 動かし方

```bash
npm install
npm run dev     # Mac のブラウザで http://localhost:5173
npm test        # 計算処理のテスト
npm run build   # 公開用ファイルを dist.nosync/ に作る
```

同じ Wi-Fi の iPhone で試すときは、`npm run dev` で表示される `Network:` の URL を Safari で開く。

## フォルダ

- `src/data/` データの型・ダミーデータ・保存
- `src/logic/` 計算（カードの締め日、負債、稼働日と売掛金、予算）
- `src/screens/` 画面ごとのファイル
- `src/ui/` 共通の部品
- `gas/` スプレッドシートに貼り付ける GAS のコードとセットアップ手順
- `docs/sheets.md` スプレッドシートの列の並び
- `node_modules` と `dist.nosync` は iCloud に同期させないため `.nosync` のフォルダに置いている
