# スプレッドシートの構成

データはすべて Google スプレッドシート1つに置く。GAS はこの列の並びで読み書きするので、列の順番は変えない（列を足すときは右端に）。

- 1行目は見出し。2行目からデータ
- 日付は `YYYY-MM-DD` の文字列（書式なしテキスト）
- 他のシートを指すところは ID で書く（名前は変わることがあるため）
- 「末日」と書ける欄は、数字の日付か「末日」

| シート | 列 |
|---|---|
| 明細 | ID / 日付 / 金額 / 区分（支出・収入）/ 支払元（現金・エポス・三井住友）/ 内容 / メールID（三井住友メールの取り込みで二重登録を防ぐ） |
| 固定費 | ID / 名前 / 金額 / 払う月（「毎月」または「6,8,10,1」）/ 払い方（口座・カード）/ 銀行ID / 引き落とし日 / カードID / カードの請求日 |
| 負債 | ID / 名前 / 種類（ローン・カード分割）/ カードID / 銀行ID / 返済日 / 借入額 / 残債 / 残債の基準日 / 毎月の返済額 / 金利（%）/ 初回返済日 |
| 銀行 | ID / 名前 / 短い名前 |
| カード | ID / 名前 / 短い名前 / 締め日 / 支払月（1=翌月）/ 引き落とし日 / 銀行ID |
| 取引先 | ID / 名前 / 請求方式（案件まとめて・月締め）/ 締め日 / 支払月（1=翌月）/ 支払日 / 個別の日当 |
| 案件 | ID / 名前 / 取引先ID / 予定のタイトル（1行に1つ。セル内で改行） |
| 予定 | タイトル / 開始日 / 終了日 / 種類（稼働・打ち消し）。GAS が iCloud カレンダーから書き込む |
| 入金の手直し | 請求ID / 入金済み（TRUE・FALSE） |
| 日当 | 適用開始日 / 日当 |
| カレンダー | 種類（稼働・打ち消し）/ 公開URL（webcal） |
| 設定 | 項目 / 値（生活費の予算（週）・生活費のカードID・繰越金の月・繰越金・事業の入金先の銀行ID） |

アプリのデータの型（`src/data/types.ts`）と1対1で対応する。
