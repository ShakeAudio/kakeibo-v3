# GAS のセットアップ手順

スプレッドシート「家計簿 v3 データ」に GAS を入れて、アプリから使えるようにする手順。最初の1回だけ。

## 1. コードを貼り付ける

1. スプレッドシートを開き、メニューの「拡張機能」→「Apps Script」
2. 左の「コード.gs」の中身を全部消して、`gas/Code.gs` の中身を貼り付ける
3. 上のプロジェクト名（「無題のプロジェクト」）を「家計簿 v3」に変える
4. 保存（Command + S）

## 2. 合言葉を作る

1. 上の関数の選択欄で `createToken` を選び、「実行」
2. 初回は許可を求められる。「権限を確認」→ 自分のアカウント →「詳細」→「家計簿 v3（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので、この警告は出るのが普通
3. 下の「実行ログ」に `合言葉: ……` と出る。この文字列をパスワード管理アプリなどに控える
   - 合言葉はスクリプト プロパティ（左の歯車「プロジェクトの設定」の一番下）に保存されている。スプレッドシートやコードには書かれない

## 3. 三井住友カードのメールにラベルを付ける

利用通知メールに Gmail のラベル `三井住友_明細` が付いていれば取り込める（以前の家計簿と同じラベル）。

- 付いていなければ、Gmail の「フィルタを作成」で三井住友カードの利用通知メールに `三井住友_明細` を付ける
- 以前の家計簿の GAS が動いたままだと、夜にメールをゴミ箱へ移す処理（`cleanupProcessedMails`）が残っている可能性がある。以前の GAS の「トリガー」を開いて、不要なら止める

## 4. カレンダーの公開 URL を登録する

1. iPhone の「カレンダー」アプリ → 下の「カレンダー」→ 稼働用のカレンダーの「i」→「公開カレンダー」をオン →「リンクを共有」でコピー
2. スプレッドシートの「カレンダー」シートに1行ずつ入れる
   - 種類「稼働」: 稼働につながる予定を入れているカレンダー
   - 種類「打ち消し」: 休演日を入れているカレンダー
3. 打ち消し用のカレンダーも同じように登録する

## 5. 自動で動くようにする

1. 関数の選択欄で `setupTriggers` を選び、「実行」（許可を求められたら手順2と同じく許可）
2. これでメールは15分ごと、カレンダーは6時間ごとに自動で読み込まれる
3. すぐ試したいときは `importSmbcMail` と `importCalendars` を実行し、「明細」「予定」シートに行が増えるか確かめる

## 6. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車から種類「ウェブアプリ」を選ぶ
3. 次のように設定して「デプロイ」
   - 説明: 家計簿 v3
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）を控える

「全員」にしないとアプリから呼び出せない。合言葉が合わない要求には何も返さないので、データは守られる。

## 7. アプリに入力する

アプリの設定（公開版では最初の画面）で、手順6の URL と手順2の合言葉を入力する。

## コードを直したとき

「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン」を「新バージョン」にして「デプロイ」。URL は変わらない。
